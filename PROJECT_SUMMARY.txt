🆘 TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────────

Issue: "API key is invalid"
→ Get new key at console.anthropic.com/api/keys
→ Update .env with new key

Issue: "client_brief.md not found"
→ cp client_brief.example.md client_brief.md
→ Fill in your client details

Issue: "Command not found: python"
→ Use python3 instead of python
→ python3 main.py --help

Issue: "Rate limited"
→ Wait a minute
→ Agent auto-retries, or try again

Issue: "Timeout"
→ Network issue or very large site
→ Try: export REQUEST_TIMEOUT=60
